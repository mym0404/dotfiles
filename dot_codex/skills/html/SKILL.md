# HTML로 설명하기

## 1. 설명할 핵심 정하기

요청과 대화 맥락에서 사용자가 이해하려는 질문을 한 문장으로 정리해요. 그 질문에 답하는 데 필요한 개념과 관계를 골라요. 사용자의 설명 수준과 범위를 따라가요.

완료 기준: 설명할 질문과 답에 필요한 핵심 내용이 정해져 있어요.

## 2. 눈으로 이해할 수 있게 구성하기

핵심 답을 먼저 보여주고, 비교는 표로, 과정은 단계로, 원인과 결과는 흐름도로 표현해요. 내용에 맞는 표현을 골라 짧은 설명과 구체적인 예시를 붙여요. 개념마다 같은 이름을 쓰고, 예시의 가정과 실제 사실을 구분해요.

여백과 글자 크기로 읽는 순서를 드러내요. 색상에는 글자나 기호를 함께 써서 의미를 전달해요. 입력값을 바꿔 결과를 보는 것이 이해에 도움이 될 때만 간단한 상호작용을 넣어요.

완료 기준: 요청한 핵심 내용이 모두 드러나고, 시각 요소가 설명하는 관계를 읽을 수 있어요.

## 3. 임시 경로에 HTML 만들기

OS 임시 디렉토리에 고유한 작업 폴더를 만들고, 그 안에 주제를 나타내는 이름의 `.html` 파일을 저장해요. CSS와 필요한 JavaScript는 파일 안에 포함해서 별도 설치 없이 브라우저에서 열 수 있게 해요.

문서 언어, UTF-8 인코딩, 모바일 viewport를 지정하고, 좁은 화면에서도 내용이 읽히도록 구성해요. 상호작용에는 기본 HTML 컨트롤과 명확한 레이블을 사용해요.

완료 기준: 설명 전체가 담긴 독립적인 HTML 파일이 임시 경로에 존재해요.

## 4. 확인하고 링크 전달하기

만든 파일을 다시 읽어 핵심 내용의 누락과 사실 오류를 확인해요. 브라우저 도구를 사용할 수 있으면 파일을 열어 글자와 도식의 잘림, 겹침, 상호작용을 확인하고 고쳐요. 직접 열어보지 못했다면 확인한 범위만 말해요.

최종 응답에는 결과를 짧게 설명하고 `[HTML 설명 보기](/절대/임시/경로/파일.html)` 형식으로 실제 파일의 절대 경로 링크를 제공해요. 전달한 HTML 파일은 사용자가 열 수 있도록 남겨둬요.

완료 기준: 수행한 확인을 통과한 파일이 있고, 응답의 링크가 그 파일을 가리켜요.
