# 안들려영어 콘텐츠 제작

저장소 루트 AGENTS.md에서 콘텐츠 제작·도메인·게시·문제 해결 문서의 경로를 확인하고, 해당 작업에 필요한 문서를 읽어요. 실제 대본·타임라인·파일 생성은 저장소의 `scripts/produce.mjs`를 사용해요. 소스 URL·영어 메타데이터·자막과 선택적 용례 후보를 입력하고, 생성 결과와 사용량을 수업별 제작 기록에 남겨요.

## 학습자 기록

제작 전에 [references/learner-profile.json](references/learner-profile.json)을 읽어요. 이것이 이미 아는 단어·표현·문법의 원본이에요. 다른 프로필을 `--profile`로 지정한 작업에서는 그 파일을 사용해요.

- 사용자가 안다고 확인한 의미·용법이나 실력 진단으로 확인한 항목만 추가해요. 영상에서 이미 설명했다거나 B1~B2를 선택했다는 이유로 아는 항목을 추정하지 않아요.
- 같은 표현의 다른 의미는 구분하고, 같은 의미에는 기존 concept ID를 재사용해요. 아는 문구를 새 ID나 다른 문형 이름으로 바꿔 다시 가르치지 않아요.
- 아는 항목의 추가 해설과 외부 용례를 제외해요. 원본 영어 문장과 문장 전체의 한국어 해석은 보존해요.
- 확인된 항목은 `know` 명령으로 표현·의미·종류·확인 근거와 함께 즉시 기록해 다음 제작에 반영해요. 임시 QA 프로필을 실제 학습자 기록에 합치지 않아요.

```sh
node scripts/produce.mjs --help
node scripts/produce.mjs validate <input.json>
node scripts/produce.mjs build <input.json>
```

## 실력 진단 요청

사용자가 진단을 시작하자고 하면 50문제를 출제해요. 쉬운 어휘부터 B1~B2 숙어·구동사·문장 구조·문법·뉘앙스·듣기 이해까지 포함해 실제로 알고 있는 의미를 구분해요. 답을 받은 뒤 근거가 있는 항목만 학습자 기록에 반영해요. 진단을 나중에 하겠다고 하면 먼저 문제를 내거나 답을 추정하지 않아요.

## 대본과 실제 용례

설명할 영어 단어·구문을 대본과 음성에서 생략하지 않아요. 각 해설은 “pain threshold는 …라는 뜻이에요”처럼 영어 대상을 먼저 말하고 뜻·쓰임을 이어가요. 안내 멘트를 뺀다는 이유로 영어 표현까지 빼거나, 화면·직전 발화에 있었다는 이유로 한국어 뜻만 남기지 않아요. 문형은 핵심 영어 표현을 직접 말한 뒤 나머지 구조를 풀어요.

단순 단어 하나의 기본 뜻을 설명할 때를 제외하면 다른 화자의 실제 영상 용례를 우선 찾아요. 학습자 기록에 없는 숙어·구동사·구문·문법·비유적 용법에는 같은 뜻과 구조의 짧은 클립을 가능하면 하나 이상 넣어요. YouGlish처럼 실제 발화를 찾아 출처·자막·구간을 확인하고 제작 입력의 exampleSources에 넣어요. 제작 CLI는 제공한 후보에서 고르므로 후보 준비를 생략하지 않아요. 맞는 용례를 못 찾으면 검색한 표현·후보와 생략 이유를 제작 기록에 남기고, 가짜 문장이나 다른 뜻의 클립으로 채우지 않아요.

## 생성 결과 확인

짧은 실제 소스로 전체 제작 명령을 실행하고, 입력에서 최종 MP4·수업 JSON·썸네일·카탈로그·사용량 기록까지 연결되는지 확인해요. 선택하지 않은 외부 용례의 영상을 내려받지 않아야 해요. 생성 도구의 음성 대조와 실제 사람의 청취 검수 여부를 구분해요. R2 게시나 App Store 배포는 별도로 요청받은 범위에서 실행해요.
