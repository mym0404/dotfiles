# Fix Self

1. 호출 인자에 실수 사항이 있으면 그것을 대상으로 삼고, 없으면 현재 대화에서 사용자가 최근 지적한 실수를 모은다. 당시 요청과 실행 기록을 대조해 잘못된 행동과 기대한 행동을 구분한다. 실수나 대상 프로젝트를 특정할 수 없으면 필요한 정보만 묻는다.
2. 그 명령을 수행할 때 참고한 지시사항 중 **해당 프로젝트 폴더 안에 실제로 존재하는 문서**를 찾는다. `AGENTS.md`, reference 파일, 프로젝트의 `SKILL.md` 등이 대상이다. 사용자 전역 지침·전역 스킬·메모리는 수정하지 않으며, 심볼릭 링크의 실제 대상도 프로젝트 안인지 확인한다. 맞는 문서가 없거나 당시 참고 여부가 불명확하면 경로를 묻고 멈춘다.
3. 후보 문서 전체와 연결된 관련 규칙을 읽고, 실수가 발생한 작업에 적용되는 가장 구체적인 위치를 고른다. 기존 규칙이 있으면 수정하고, 없으면 필요한 지침만 추가한다. 같은 뜻을 여러 문서에 복제하지 않는다.
4. 실수의 재발을 막는 규칙을 간결하게 쓴다. 관련된 중복·충돌·낡은 문구는 함께 정리한다.
5. 수정한 문서 전체와 diff를 다시 읽어 모든 대상 실수에 대응하는 지침이 있는지, 관련 규칙과 일치하는지, 변경 파일의 실제 경로가 프로젝트 내부인지 확인한다. 수정 파일 링크와 반영한 지침을 짧게 보고한다.
